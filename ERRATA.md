# Errata and change requests

Use this repository's issue tracker to report:

- ambiguity or inconsistency in normative text;
- an incorrect or broken cross-reference;
- an implementation result that conflicts with a requirement;
- a missing threat, effect path, or conformance residual; or
- an error in the Deployment Guide.

Include the affected file and heading, the working-draft snapshot or released version,
the observed problem, and proposed correction if available.

Normative corrections are not silently edited into the official specification. They
enter the `ZTG-AMEND-NNN` procedure described in [`GOVERNANCE.md`](GOVERNANCE.md).
Guide corrections remain attributable changes under the ZTG Documentation License 1.0.
